## About Me

I design and build **AI-integrated web products** end to end — idea, interface, backend, data model, deployment. No handoffs, no missing layer.

I start from my own ideas, design them in Figma, and build them with an **AI-native workflow**: Claude Code wired to my codebase through **MCP servers**, plus MiniMax and other models for generation and review. When I hit something I don't understand, I go and study the concept first, then debug it with the same tools. That loop is how I taught myself scalability, auth, caching, storage and production deployment.

```
  Idea  ──▶  Figma  ──▶  Architecture  ──▶  Build (Claude Code + MCP)  ──▶  Ship  ──▶  Maintain
                                  ▲                                                      │
                                  └───────────────  learn → debug → refactor  ◀──────────┘
```

**What I care about:** systems that actually run in production, interfaces people enjoy using, and agents that do real work instead of demoing well.
